# 🐔 Galinhada

## 📌 Sobre o projeto

O **Galinhada** é um projeto desenvolvido em Python com o objetivo de auxiliar na gestão de uma pequena produção de ovos de galinha.

A ideia surgiu a partir de uma necessidade real: um amigo que atualmente trabalha com produção de ovos me pediu uma ferramenta que pudesse ajudá-lo a visualizar melhor os números do seu negócio.

A primeira versão é um protótipo simples, capaz de realizar cálculos básicos relacionados à produção, consumo de ração, custos e faturamento.

## ⚙️ Funcionalidades atuais

* Cálculo da quantidade estimada de ovos produzidos
* Cálculo do consumo de ração
* Cálculo do custo da ração
* Cálculo do faturamento
* Cálculo do resultado após o custo da ração

## 🚀 Próximas melhorias

O projeto continuará sendo desenvolvido e receberá novas funcionalidades, como:

* Permitir informar o valor pago pela ração (que atualmente só é possivel alterando o valor no código)
* Permitir definir o preço de venda dos ovos (que atualmente só é possivel alterando o valor no código)
* Cadastro de outros custos da produção
* Cálculo mais completo de custos e lucros
* Histórico da produção
* Relatórios
* Gráficos para visualização dos custos, faturamento e resultados
* Melhorias na usabilidade do sistema
